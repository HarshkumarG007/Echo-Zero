# ECHO//ZERO

**"You are made of the same grief you are trying to resolve."**

ECHO//ZERO is a vertical slice of a sci-fi/fantasy mystery game where you play as ZERO, an entity reconstructed by a grieving AI named ECHO. Armed with the **RECALL** ability, you must navigate the collapsing architecture of the Aerie, piece together contradictory memory fragments, and confront the truth of your own creation.

## About This Build

This project is a portfolio-grade demonstration of **agentic software engineering** built using Google Antigravity + Google AI Pro. It is not just a game prototype, but a technical showcase of integrating local Machine Learning models into a Unity 6 production environment.

### Technical Highlights
* **Local ML Inference:** Powered by Unity Sentis, this build runs ONNX models directly on your hardware—no cloud API keys or internet connection required.
* **ML-Driven Pursuit:** The hostile "Drift" entities use a trained neural network to predict your trajectory, leading to dynamic, emergent interception tactics rather than simple pathfinding.
* **Adaptive Narrative:** Mira, your guide, dynamically adjusts her dialogue based on an "Aggression Score" calculated in real-time from your playstyle telemetry.
* **Agent-Driven Architecture:** The entire underlying architecture—from the Service Locator and Event Bus to the Utility AI Brain—was planned, coded, and tested by an AI software engineer adhering strictly to documented design decisions (ADRs).

## Controls
* **WASD:** Move
* **Mouse:** Look
* **Right Mouse Button (Hold):** Activate RECALL
* **P or Esc:** Pause / Save Menu

## Installation
1. Download `ECHO_ZERO_Windows64.zip`.
2. Extract the folder to your preferred location.
3. Run `ECHO_ZERO.exe`.

## System Requirements
* **OS:** Windows 10/11 (64-bit)
* **Processor:** Quad-core Intel or AMD processor, 2.5 GHz or faster
* **Memory:** 8 GB RAM (16 GB recommended)
* **Graphics:** Dedicated GPU recommended (e.g., RTX 3060/4060 or equivalent) for optimal Sentis tensor operations.
* **Storage:** 500 MB available space
